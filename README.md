# 申五月 / Shen Wuyue

数码评测编辑，写笔记本、手机和智能硬件的深度评测。比起形容词，我更相信能被复现的数字：同一段测试跑三次，功耗、帧率和续航折算出来的差距，才值得写进结论。

平时的工作流大概是：测样机 → 记数据 → 写稿 → 校对。中间重复的环节，能写成脚本的就写成脚本。

## 在做的事

- **[zh-copy-lint](https://github.com/shenwuyue0202/zh-copy-lint)** — 中文文稿排版检查器。中英文空格、半角标点、省略号、破折号这些「自己看不出来、发出去会被挑出来」的问题，跑一遍就能定位到行列，支持自动修复。
- 评测稿的数据整理：把 PCMark、AIDA64、功耗仪导出的零散记录合并成可对比的表格。
- 续航折算：用实测时长反推平均功耗，再和电池容量对照，避免「官方说多少就是多少」。

## 关注的方向

- 移动端芯片的能效比：同样的功耗预算下能做多少事
- 笔记本的性能释放与散热调度
- 智能手表和穿戴设备的健康数据可信度
- 文档工具链：docx、Markdown 和出版排版之间的来回转换

## 常用的东西

`Python` · `python-docx` · `Pillow` · `Markdown` · `Git` · 一点点前端
